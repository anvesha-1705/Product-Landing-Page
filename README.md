# 🛍️ Savana — Fashion Product Landing Page

A responsive product landing page for a fashion e-commerce brand, built with HTML, CSS, and JavaScript.

---

## 📌 Overview

Savana is a single-page landing page designed to showcase a fashion brand's product catalog, seasonal deals, and curated collections. The layout adapts across desktop, tablet, and mobile viewports.

---

## ✨ Features

- **Hero Section** — Brand introduction with a call-to-action and social proof (ratings, customer count)
- **Summer Deals** — Category cards for Tops, Bottoms, and Accessories with promotional tags
- **Featured Collections** — Editorial-style banner grid highlighting curated product edits
- **Customer Reviews** — Testimonial section with star ratings and verified buyer labels
- **Newsletter Signup** — Modal form with a confirmation state on submission
- **Dark Mode** — Toggle between light and dark themes
- **Responsive Layout** — Optimized navigation, grid, and typography across screen sizes

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (DOM interactivity, theme toggle, modal handling)
